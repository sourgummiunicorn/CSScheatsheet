CSS RULE ANATOMY

Every look starts with a rule.

CSS gives instructions.
Browsers make them visible.

style.css
p {
  color: #EA580C;
}
One rule can style every matching paragraph
p

Selector — chooses which HTML element or elements the rule will style.

color

Property — names the visual feature you want to change.

#EA580C

Value — tells the browser which setting to use for that feature.

✳

What’s happening here? CSS selects every paragraph, then makes its text orange. The curly braces hold the declarations; each declaration ends with a semicolon.

WAYS TO NAME A COLOR
Different labels. Same orange.
  • salmon named color
  • #EA580C hex color
  • rgb(234, 88, 12) red, green, blue
  • rgba(234, 88, 12, 0.6) with 60% opacity

      
SERIF WITH FALLBACKS
font-family: Georgia, "Times New Roman", serif;
If Georgia is unavailable, the browser tries Times New Roman, then another serif font.
SANS-SERIF WITH FALLBACKS
font-family: Arial, Helvetica, sans-serif;
A font stack gives the browser friendly backup choices.

      

        
GOOGLE FONTS
Bring Roboto into your page.
Google Fonts hosts typefaces that you can load with one HTML link, then use with font-family.
Roboto says hello, with a friendly fallback close behind.

        

          
1
Add this inside <head>.
index.html
<link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap" rel="stylesheet">

          
2
Use it in your CSS.
style.css
body {
  font-family: "Roboto", Arial, sans-serif;
}
The fallback fonts keep text readable if Roboto has not loaded yet.

06
UNITS AND INTERACTION
Choose a size that fits the job.
Not every measurement
means the same thing.

      
Click an arrow for a larger interactive example.

      

        
px
Fixed sizing
Pixels are a fixed unit. Good for a border, icon, or exact small gap.
Quick rule: 1pt ≈ 1.33px, so 12pt ≈ 16px.
border: 2px solid #FDBA74;

        
rem
Scalable text
Think of <html> as the page’s starting text size. rem uses it, not the parent: root 16px means 1rem = 16px.
font-size: 1.25rem;

        
%
Relative to a parent
About %: it is relative to the parent. If a parent is 20px, then 100% is 20px, not 16px.
width: 80%;

        
vw / vh
Relative to the browser
vw uses browser width; vh uses browser height.
font-size: 3vw;
