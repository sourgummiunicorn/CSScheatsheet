# CSS Field Guide

A friendly, beginner-focused CSS cheatsheet with short explanations, live previews, and small interactions.

## Why this is useful

Learning CSS is easier when you can change one thing and immediately see what happened. This guide helps beginners:

- Understand the parts of a CSS rule: selector, property, and value.
- See how text, colors, spacing, sizing, and positioning change a page.
- Practice essential selectors without jumping straight into advanced syntax.
- Compare `px`, `rem`, and `%` through interactive examples.
- Learn when `static`, `relative`, `absolute`, `fixed`, and `sticky` positioning are helpful.
- Build confidence by completing small CSS practice missions.

## How to use it

Open `index.html` in a browser. Follow the sections in order, try the controls, and use the copy buttons to reuse an example in your own project.

## Files

- `index.html` — guide content and structure
- `style.css` — sticker-planner visual design and responsive styles
- `script.js` — interactive previews, pop-ups, and practice activities
